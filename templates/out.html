Historical Weather Results: These site-specific design values are derived from the historical Daymet weather record selected for this analysis. All displayed design values are reported in inches. NOAA Atlas 14 values from the nearest Atlas grid point are included for comparison purposes only. Because Atlas 14 uses different data sources and calculation methods, its values are not directly comparable (i.e., not an apples-to-apples comparison) with the Daymet PREC-IDF or NG-IDF values. In contrast, NG-IDF can be directly compared with PREC-IDF because both use the same Daymet data source and calculation method.

How to use these outputs:
  • PREC-IDF reports precipitation-only design-storm depth for each duration and average recurrence interval (ARI).
  • NG-IDF reports water available for runoff, incorporating cold-region processes such as snowmelt and rain-on-snow in addition to rainfall.
  • % Difference (Impact Summary table) compares NG-IDF with Daymet PREC-IDF. Positive values suggest potential under-design if following the standard PREC-IDF method. E.g., a +20% difference suggests the NG-IDF value is 20% higher than the PREC-IDF value.
  • Annual-maximum tables (in the Detailed Data Tables) list the largest event in each water year. The event mechanism identifies whether the annual runoff maximum was driven by rainfall (R), snowmelt (M), or rain-on-snow (ROS).
  • The reported 90% confidence intervals describe uncertainty in the fitted IDF estimates and can support risk-informed design decisions.

NG-IDF vs PREC-IDF (Daymet)

ARI = Average Recurrence Interval. Difference = NG-IDF − PREC-IDF. % Difference = (NG-IDF − PREC-IDF) / PREC-IDF × 100.

How to read % Difference: A positive value (red) means NG-IDF is higher than PREC-IDF, which suggests potential under-design if the standard PREC-IDF method is followed. For example, +20% means the NG-IDF value is 20% higher than the PREC-IDF value. A negative value (blue) means NG-IDF is lower than PREC-IDF.
